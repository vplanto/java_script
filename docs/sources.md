# Реєстр першоджерел

Централізований список офіційних специфікацій і довідників курсу. У лекціях посилайтесь як **[N]**, без копіювання фрагментів тексту специфікацій.

---

## Основні джерела

**[1] HTML Living Standard (WHATWG)**  
https://html.spec.whatwg.org/

**[2] MDN Web Docs (Mozilla)**  
https://developer.mozilla.org/

**[3] ECMA-262 — специфікація JavaScript**  
https://tc39.es/ecma262/

**[4] CSS Specifications (W3C / CSSWG)**  
https://www.w3.org/Style/CSS/specs.en.html

**[5] HTTP — RFC 9110 (семантика та вміст)**  
https://www.rfc-editor.org/rfc/rfc9110.html

**[6] Fetch Standard (WHATWG)**  
https://fetch.spec.whatwg.org/

**[7] OWASP Cheat Sheet Series**  
https://cheatsheetseries.owasp.org/  
*(зокрема XSS, CSRF)*

**[8] Web Cryptography API (W3C)**  
https://www.w3.org/TR/WebCryptoAPI/

**[9] JSON — RFC 8259**  
https://www.rfc-editor.org/rfc/rfc8259.html

**[10] Chrome Developers — Inside look at modern web browser**  
https://developer.chrome.com/blog/inside-browser-part1/

**[11] V8 — документація рушія JavaScript**  
https://v8.dev/docs

**[12] Закон України № 4742-IX «Про освіту»**  
https://zakon.rada.gov.ua/laws/show/4742-20

## Примітки

- Педагогічні приклади (Wikipedia, демо-сайти, Python Tutor) у воркшопах **не** входять до цього реєстру — вони лише для практики.
- Операційні API третіх сторін (наприклад, OpenWeatherMap у воркшопі 7) — зовнішні сервіси, не нормативні джерела курсу.
